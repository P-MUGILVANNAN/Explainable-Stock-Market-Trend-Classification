# Research & Experimental Methodology

This directory contains standalone research experiments, benchmark pipelines, and empirical evaluation scripts supporting the academic investigation:

> **"Does incorporating financial news sentiment improve stock market trend classification compared with models that use historical stock prices and technical indicators alone?"**

---

## 1. Research Directory Structure

```
research/
├── experiments/
│   ├── run_paired_experiments.py   # Paired evaluation (Group A vs Group B) with bootstrap hypothesis testing
│   └── finbert_ablation_study.py   # Feature ablation study (isolating individual FinBERT sentiment metrics)
├── evaluation/
│   └── model_benchmarks.py         # 5-Model comparative benchmark (LR, RF, XGB, SVM, LSTM)
├── reports/
│   ├── research_findings_summary.md# Academic empirical synthesis and conclusions
│   ├── paired_experiment_results.csv (Generated by run_paired_experiments.py)
│   ├── ablation_study_results.csv    (Generated by finbert_ablation_study.py)
│   └── model_benchmark_results.csv   (Generated by model_benchmarks.py)
└── README.md                       # Research guide & execution instructions
```

## 2. Formal Statistical Hypotheses

For any given machine learning architecture $M$ and out-of-sample evaluation metric $S$ (such as Macro F1-Score or Balanced Accuracy):

- **Null Hypothesis ($H_0$)**: Incorporating FinBERT financial news sentiment yields no improvement over historical prices and technical indicators alone:
  $$\Delta S = S_{\text{Price+News}} - S_{\text{Price-Only}} \le 0$$

- **Alternative Hypothesis ($H_1$)**: Incorporating FinBERT financial news sentiment produces a statistically significant performance improvement:
  $$\Delta S = S_{\text{Price+News}} - S_{\text{Price-Only}} > 0$$

- **Significance Criterion**: $\alpha = 0.05$ evaluated via non-parametric **500-iteration bootstrap resampling** with 95% empirical confidence intervals.

---

## 3. Strict Experimental Controls

1. **Zero Lookahead Bias**: Chronological 70% train / 10% validation / 20% test splitting. Future dates are strictly embargoed.
2. **Leakage-Free Scaling**: Feature transformers (`StandardScaler`) are fit *exclusively* on the training partition.
3. **News Timestamp Cutoff**: News articles are filtered by strict timestamp publication prior to market close of trading day $t$.
4. **Three-Class Target Definition**:
   $$y_t = \begin{cases}
   \text{UPWARD} & \text{if } R_{t \to t+h} > +0.5\% \\
   \text{DOWNWARD} & \text{if } R_{t \to t+h} < -0.5\% \\
   \text{SIDEWAYS} & \text{otherwise}
   \end{cases}$$

## 4. How to Execute the Research Experiments

### Run the Paired Hypothesis Test (Group A vs Group B)
```powershell
python research/experiments/run_paired_experiments.py --symbols AAPL MSFT NVDA TSLA RELIANCE.NS --model xgboost
```

### Run the FinBERT Sentiment Feature Ablation Study
```powershell
python research/experiments/finbert_ablation_study.py --symbol AAPL --model xgboost
```

### Run the 5-Model Benchmark Suite
```powershell
python research/evaluation/model_benchmarks.py --symbol AAPL
```
